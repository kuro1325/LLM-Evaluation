# LLM Evaluation

一个面向产品经理与项目经理的轻量级大模型业务适配评测工具。

它在相同原文、相同任务规则和相同运行限制下，同时调用两个模型；再由匿名裁判结合人工标注检查点，评估质量、事实保护、效率与成本，输出可用于选型和迭代的建议。

## 在线体验

[打开 LLM Evaluation 在线版](https://kuro1325.github.io/LLM-Evaluation/)

> 真实评测需要填写自己的 OpenRouter API Key。Key 仅保存在当前浏览器会话中，关闭标签页后清除。

## 核心功能

- 支持两个模型同时评测
- 支持办公、法律、英语教育场景
- 支持总结、提取、分类、生成、公文编校、知识问答、作业批改、分级讲解和作文辅导任务
- 内置模拟业务样本与人工标注检查点
- 支持质量优先、效率优先、成本优先和自定义权重
- 实时展示各模型的生成状态
- 展示耗时、Token 和实际费用
- 使用独立裁判模型进行匿名质量评估，并核验人工检查点
- 展示质量、效率、成本分项及最终业务适配分
- 支持将重点样本加入本地回归集，用于 Prompt、模型和权重变更后的复测
- 支持认可或不认可评分反馈
- 支持单模型失败、双模型失败、超时等异常提示

## 评分方式

最终结果不是模型绝对能力排名，而是当前任务和当前权重下的“业务适配分”。

- 质量：由匿名裁判模型依据原文、用户要求和任务规则判断
- 效率：根据模型完成时间由代码计算
- 成本：根据 OpenRouter 返回的实际费用由代码计算
- 总分：按照用户设置的质量、效率、成本权重计算

默认权重：

- 均衡：三个维度各约三分之一
- 质量优先：质量 40%，效率 30%，成本 30%
- 教学质量优先：教学质量 70%，效率 20%，成本 10%
- 效率优先：效率 40%，质量 30%，成本 30%
- 成本优先：成本 40%，质量 30%，效率 30%

## 使用方式

1. 点击右上角“配置 API Key”
2. 输入自己的 OpenRouter API Key 并验证
3. 将运行模式切换为“真实评测”
4. 选择测试样本和两个模型
5. 设置评分权重
6. 检查或修改原文、编校规则与人工检查点
7. 点击“开始评测”

一次完整真实评测通常包含三次请求：模型 A、模型 B 和裁判模型，因此会消耗 OpenRouter 额度。

## 安全说明

- API Key 仅写入 `sessionStorage`
- Key 不写入数据库、长期本地存储或日志
- 仓库不包含任何真实 API Key
- 默认不保存用户原文、模型回答和历史评测
- 生产网页通过 HTTPS 访问

请不要输入高度敏感、受保密约束或不适合发送给第三方模型服务的数据。

## 本地运行

环境要求：Node.js 22.13 或更高版本。

```bash
npm install
npm run dev
```

打开终端中显示的本地地址即可。

生产构建：

```bash
npm run build
```
